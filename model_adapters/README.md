# Model adapter notes

- macOS default: stabilityai/stable-diffusion-xl-base-1.0 through Diffusers and MPS.
- Windows default: runwayml/stable-diffusion-v1-5. Use CPU or verified XPU/Intel OpenVINO builds only.
- FLUX.1-schnell is optional; verify its current license and commercial terms before use. It is not enabled by default.
- Real-ESRGAN models require separately obtained official weights and compatible packages.
